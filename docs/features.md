# Chat Viewer — 공식 Synology Chat 클라이언트와 다른 점

사내 Synology Chat을 더 빠르고 편하게 쓰기 위해 만든 대체 데스크톱 클라이언트입니다. 서버는 그대로 두고(같은 계정·같은 데이터), 클라이언트만 바꿉니다. 공식 앱과 번갈아 써도 서로 충돌하지 않습니다.

## 속도·구조
- **네이티브 웹뷰(Tauri)** — 공식 앱은 DSM 데스크톱 전체를 Electron에 띄우지만, 이 앱은 Chat API만 직접 호출합니다. 실행과 채널 전환이 훨씬 빠르고 메모리도 적게 씁니다.
- **로컬 메시지 색인(SQLite FTS5)** — 참여한 모든 채널의 메시지를 로컬에 색인해 검색이 즉시 됩니다. 실시간으로 들어오는 메시지도 바로 색인됩니다.

## 검색 (공식: 단어 완전 일치만 가능)
- **부분 일치** — "C동가실래요"를 "C동"으로 찾습니다. 공식 검색은 띄어쓰기 단위로만 일치해 한국어 조사에 약합니다.
- **검색 대상 선택** — 전체 / 메시지 본문 / 파일명.
- **투표 선택지·링크 제목·설명·스니펫 미리보기·해시태그**까지 검색됩니다.
- **파일 종류·확장자 필터** — 이미지·동영상·오디오·PDF·문서·스프레드시트·프레젠테이션·압축·코드·기타, 확장자 직접 입력. 게시판 파일 탭에도 같은 필터.
- 결과에서 바로 해당 메시지로 점프.

## 사이드바
- **사람 이름으로 검색** — 이름 일부를 치면 그 사람과의 1:1 대화와 함께 속한 채널이 사람별로 묶여 나옵니다.
- **정렬** — 섹션마다 최근 활동순 / 이름순 / 직접 정렬(드래그). **맨 위 고정**, **안 읽은 방 위로** 옵션.
- **커스텀 그룹** — 채널을 내 기준으로 묶어 섹션으로 표시(예: "프로젝트 A", "관제").
- **숨기기 두 가지** — 모든 기기에서 숨기기(서버, 공식 앱과 동일) / 이 앱에서만 숨기기. 숨긴 채널 목록은 사이드바 맨 아래에서 바로 확인·복구.
- **새 메시지 섹션** — 알림을 받기로 한 채널 중 안 읽은 방만 모아 최상단에 표시(멘션 우선). 별도 "새 메시지" 페이지에서는 알림 끈 방까지 포함해 보고 모두 읽음 처리.
- 섹션 접기/펼치기, 사이드바 접기(⌘\), 내 공간은 항상 다이렉트 메시지 맨 위.
- 비활성/삭제된 사용자는 배지로 표시.

## 메시지
- **WYSIWYG 입력창** — 굵게/기울임/취소선/인용/목록/코드가 입력창에서 바로 보입니다(전송 시 Synology 마크업으로 변환되어 공식 앱에서도 동일하게 보임).
- **Enter 전송** — Enter는 전송, Shift+Enter는 줄바꿈(인용·목록 안에서는 새 줄·새 항목). 코드 블록 안에서만 Enter가 줄바꿈이고 빈 줄에서 Enter 또는 ⌘/Ctrl+Enter로 전송. 한글 조합 중 Enter는 조합을 확정한 뒤 바로 전송되며(WKWebView가 조합 직후 Enter를 삼키는 문제를 `handleDOMEvents`에서 받아 처리), 문서는 조합 반영 후 한 틱 뒤에 읽고, 그때도 에디터 상태가 화면 글자와 다르면(IME가 마지막 글자를 늦게 확정하는 WebView2·WKWebView 경우) 25ms 간격으로 최대 8번 다시 맞춰 본 뒤 전송해 마지막 글자가 잘리지 않습니다. 터치 화면은 Enter 줄바꿈, 보내기 버튼 전송. **Home/End**는 현재 줄의 처음/끝으로 커서 이동(Shift로 선택 확장), ⌘/Ctrl+Home/End는 글 전체의 처음/끝 — macOS 웹뷰가 Home/End를 화면 스크롤로 처리하던 것을 Windows·공식 앱과 같게 맞춤.
- **댓글 인라인 표시** — 댓글이 메시지 아래 기본으로 펼쳐지고, 메시지별·전체 접기 가능. 답글 입력창은 요청했을 때만.
- **부드러운 스크롤** — 새 메시지·내 전송 시 자연스럽게 내려가고, 위를 보고 있을 때는 "새 메시지 N개" 버튼만.
- **시간 구분선** — 날짜뿐 아니라 30분 이상 대화가 끊기면 재개 시각으로 구분.
- **반응 hover** — 누가 반응했는지 바로 표시.
- **전송 실패 처리** — 서버 전송 제한(연속 전송) 등으로 실패하면 원인과 함께 재전송 / 취소.
- 프로필 카드 — 아바타·이름을 누르면 프로필 카드, 거기서 1:1 메시지로. 1:1이 없으면 서버에 방을 만들어 바로 연다(공식 규칙대로 DSM 계정과 챗봇만; 게스트·웹훅 봇·삭제/비활성 계정은 버튼이 꺼지고 이유가 표시). 실패하면 토스트로 원인(예: 서버에 Chat 계정 없음)을 알린다.
- 내 프로필 — 닉네임·소개·이메일·부재 중 표시, 프로필 사진 변경과 제거(공식 앱과 같은 `remove_avatar` 호출, 저장 시 적용).
- **읽음 표시(카톡식)** — 내 메시지 옆에 아직 읽지 않은 사람 수(1:1은 "1")를 표시하고 모두 읽으면 사라진다. 누르면 안 읽은 사람 목록. 서버가 읽음 이벤트를 push하지 않으므로 보고 있는 채널의 내 최신 글 몇 개만 10초마다 `Post get_read_status`로 조회(창이 활성일 때만, 내 공간·암호화 채널 제외). NAS 관리자 설정 `allow_read_status`가 꺼져 있으면 표시도 호출도 없고 설정 체크박스가 비활성(설정 → 알림).
- **사진 묶음(갤러리)** — 같은 사람이 2분 안에 연속으로 올린 "맨 사진"(설명 글·반응·댓글·고정·북마크가 없는 이미지) 2장 이상은 한 행의 격자(2·4장은 2열, 그 외 3열, 최대 9칸 + "+N")로 묶인다. 타일을 누르면 이미지 뷰어, 타일 호버로 다운로드·삭제(내 사진). 사진에 반응·댓글 등이 생기면 그 사진은 묶음에서 빠져 일반 행으로 돌아간다.
- 이모지 피커·자동완성(:shortname:), 멘션 자동완성, 드래그앤드롭/붙여넣기 업로드, 이미지 뷰어(←/→·화면 화살표로 채널의 이전·다음 이미지, 로드된 메시지가 끝나면 이전/다음 페이지를 더 받아 이어서 탐색, 보고 있는 이미지로 대화가 스크롤됨, 새 창에서 열기 `index.html?image=&channel=`), 스니펫 코드 하이라이트, 투표, 예약 메시지, 편집/삭제/고정/북마크.

## 정보 구조
- 헤더에는 네 가지만: **검색**(⌘K, 화면 가운데 검색 팔레트), **멤버 수**(⌘⇧M), **정보**(⌘I), **알림 토글**. 채널명·목적을 눌러도 정보 패널이 열립니다(헤더의 빈 공간은 창 드래그). ⌘I는 입력창 안에서는 기울임이고 그 밖에서만 정보 토글. 패널은 대화 영역 클릭·입력창 클릭·Esc·채널 전환으로 닫히며, 입력창에 **글자를 치는 것만으로는 닫히지 않습니다**. 창 너비가 1124px 미만이면 패널이 대화를 밀지 않고 위에 겹쳐 뜹니다.
- **검색 팔레트**: 입력·범위(현재/전체 채널)·대상·필터·결과가 한 창에. **Enter는 검색 실행**(입력 지연 없이 바로 조회)이고, ↑↓로 결과를 고른 뒤 Enter를 쳐야 그 메시지로 이동하며 닫힌다. 한글 조합을 끝내는 Enter는 무시(결과로 튀지 않음). 결과 미리보기는 3줄로 자르되 빈 줄을 접고 코드 블록은 첫 줄만 보여 빈 칸·과대 높이가 생기지 않는다. 마지막 검색어는 다시 열면 그대로, 필터는 새로 시작.
- **채널 정보 패널** 하나로 정보(목적 편집·알림 수준·음소거·즐겨찾기·나가기) / 멤버 / 게시판(고정·파일·링크·투표) / **내 항목**(이 채널의 북마크·스레드·리마인더·예약 메시지)을 2단 탭으로. 오른쪽 패널은 이것 하나뿐입니다.
- 여러 명이 모인 대화방은 겹친 아바타 아이콘으로 1:1과 구분됩니다.
- **내 컬렉션** — 북마크·구독 스레드·리마인더·예약 메시지를 사용자 단위로 한곳에.
- **채널 찾기 · 만들기** — 참여 가능한 공개 채널 / 내가 참여한 채널 / 비활성 채널을 한 화면에서. 새 채널 만들기 분리.
- **채널 알림 설정 한눈에** — 모든 채널의 데스크톱/모바일 알림 수준과 음소거를 표로 보고 일괄 변경.
- **내 프로필** — 사진·닉네임·소개·이메일·부재 중 설정.
- **정보 페이지** — 프로필 메뉴 → 정보 · 업데이트는 팝업이 아니라 채팅 영역을 채우는 페이지. 버전·업데이트 확인, **이번 버전의 새 기능**, 단축키 표(⌘/Ctrl 자동 표기, 서식은 입력 마크업도 함께), 알아 두면 좋은 것, 계정·서버. 전체 변경 내역은 앱에 두지 않고 GitHub(`chat-viewer-releases`의 `CHANGELOG.md`·릴리스 노트)로 링크. 업데이트 직후의 작은 "바뀐 점" 팝업은 그대로(건너뛴 버전 포함 최대 3개).
- **프로필 메뉴** — 공식 순서 그대로(설정 · 통합 · 부재 중 · 알림 일시 중지 · 보관 뷰어 · 도움말 · 정보)이되, **브라우저로 나가는 항목은 ↗ 아이콘과 "브라우저에서 열기" 머리글**로 앱 안 항목과 구분됩니다.
- **통합** — 수신·발신 웹훅과 슬래시 명령을 앱 안에서 조회(활성 상태·채널·만든 사람). 만들기·편집은 공식 웹으로 연결.
- **보관 뷰어** — 보관·폐쇄됐거나 내가 나간 채널의 대화 기록을 종류별(비공개·공개·개인 대화·봇)로 보고, 기간별 기록을 열어 읽기 전용으로 봅니다(이전 메시지 더 보기 지원). 공식 보관 뷰어(별도 DSM 앱)로 가는 버튼도 있습니다.
- **알림 일시 중지(스누즈)** — 20분~24시간 프리셋과 매일 정해진 시간. 서버 설정이라 공식 앱·모바일에도 적용. 스누즈 중에는 아바타에 표시.
- **시스템 알림** — 새 메시지를 OS 알림 센터에 표시(채널별 데스크톱 수준·음소거·스누즈를 따르고, 보고 있는 채널은 제외). 끔 / 무음(알림 센터만) / 소리 세 모드와 알림음 선택, Dock 아이콘에 안 읽은 수(멘션 우선) 배지, 테스트 버튼, OS 알림 설정 바로가기. 설치·권한은 `docs/install.md`.
- **사이드바 채널·사람 찾기**: 입력창 오른쪽 ✕(또는 Esc)로 검색어를 지운다. 결과에서 채널·1:1을 누르면(이미 열린 채널이어도) 검색어와 필터가 자동으로 지워져 목록이 원래대로 돌아온다. 프로필 카드만 여는 "1:1 없음" 행과 우클릭 메뉴 작업은 검색을 유지한다. 관심이 다른 곳으로 옮겨 가면(페이지 전환, Enter로 메시지 검색 팔레트 열기, 대화·입력창 영역 클릭·포커스, 이 창이 포커스를 잃음: 다른 Chat Viewer 창이나 다른 앱으로 넘어가는 경우 모두) 검색어도 자동으로 지워진다.
- **붙여넣기는 항상 서식 없는 텍스트**: 다른 앱·웹에서 복사한 굵게·링크·글꼴·표 등은 버리고 글자만 들어간다. 줄바꿈과 빈 줄, 공백은 그대로 유지(탭은 공백 4칸). 코드 블록 안에서는 줄바꿈 그대로 삽입. 이미지·파일 붙여넣기는 기존처럼 첨부로 처리.
- **우클릭 기본 메뉴(Inspect Element 등)**: 배포 빌드에서는 막는다. 입력창·텍스트 필드에서만 기본 메뉴(잘라내기·복사·붙여넣기·맞춤법)가 열리고, 앱이 직접 만든 메뉴(채널 행 등)는 그대로 열린다. dev 빌드는 기본 메뉴를 그대로 둔다.
- 채널 종류 아이콘(공개 #, 비공개 자물쇠, 봇, 그룹 대화 겹친 아바타)이 사이드바·알림 표·받은 편지함·검색·관리 페이지에서 모두 같은 컴포넌트로 통일.

## 설정 동기화
- 정렬·그룹·고정·숨김·댓글 표시 설정은 **내 공간의 스니펫 메시지 하나**에 저장되어, 재설치하거나 다른 PC에서 로그인해도 그대로 복원됩니다(Synology 사용자 설정 API에는 자유 저장 칸이 없어 내 공간을 씁니다). 해당 메시지는 "자동 관리" 표시로 보이며 삭제하지 않으면 됩니다.

## 아직 없는 것 (공식에는 있음)
- 암호화 채널, 커스텀 스티커 전송, 리마인더 생성, 게스트 사용자, 통합(봇·웹훅) 만들기·편집(조회만 가능), 작업 메뉴, 보관된 채널 복구(서버 API 없음, 관리자 콘솔 필요).
