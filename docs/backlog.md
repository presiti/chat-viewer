# 백로그 (메모)

사용자가 "당장 구현 아님, 기록만"으로 남긴 항목. 구현 순서·방식은 미정.

1. **작업 메뉴** — Synology 기능(슬래시 명령/작업 통합 메뉴). 공식 앱의 "작업" 항목 조사 필요.

## 구현됨 (2026-11-04)
- 채널별 북마크·스레드·리마인더·예약 메시지 뷰 → 채널 정보 패널 "내 항목" 탭.
- 스누즈(일회성 프리셋 + 매일 예약) → 프로필 메뉴 "알림 일시 중지". `User.Preference set v4 {snooze, snooze_schedule_enable/start/end}`.
- 프로필 메뉴: 설정 · 통합(앱 내 조회, 편집은 공식 웹) · 부재 중 · 보관 뷰어 · 도움말(외부) · 공식 웹(외부) · 정보.
- 시스템 알림(소리·Dock 배지) — `docs/features.md` 참고.
